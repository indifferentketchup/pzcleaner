pzcleaner:

indifferent broccoli chunk cleaner tool for project zomboid B42

Reset part of a Project Zomboid map

For Build 42 saves. Every chunk a player has walked through is saved as its own file. Delete the file and the game builds that chunk fresh the next time someone gets close: loot back, zombies back, player damage gone. This page shows which chunks your save has, lets you box the ones to reset, and deletes those files for you.

1. Open your save folder

Stop the server first, and keep a copy of the save. Deleted chunk files do not go to the recycle bin.

Log in with your server's SFTP details, or pick a save folder on this computer. It's the folder that holds map_meta.bin.

This browser can't open a folder for editing. Use Chrome, Edge or another Chromium browser on a desktop.

2. Box the areas to reset

  • saved chunk
  • will be deleted
  • safehouse
  • keep box
  • player

Drag to draw a box. Scroll to zoom. Hold Shift and drag, or right-drag, to pan. "Box the whole map" covers the whole world, modded areas included. Only saved chunks are deleted, and they turn red.

      never delete

      Keep boxes are always protected, and are remembered on this computer for a save folder with the same name.

      selection in cells left with no chunk files, also delete vehicles

      The game only spawns fresh vehicles in a chunk that has none on record, so leave this off and the old ones stay put, including players' cars. Ticking it edits vehicles.db and keeps a copy of the original.

      undo

      Unticked, files move to a trash folder, pzcleaner-backup in the Zomboid folder beside Saves, so they can be put back. That is slower on big selections, and it takes up the same disk space until you empty it.

      If you can't find the save folder

      The folder is named after the save, or after the server for multiplayer. It's the one with map_meta.bin and a map folder in it.

      Rented or dedicated server
      Open a save and log in with the SFTP details from your host's panel. The save is Zomboid/Saves/Multiplayer/<server name>, and on some hosts the Zomboid folder has another name, such as server-data.
      Windows
      Paste %USERPROFILE%\Zomboid\Saves into the folder picker's address bar, then open the game mode and the save.
      Linux
      ~/Zomboid/Saves, same folders as Windows.
